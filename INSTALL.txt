CHEMICAL SCANNER - INSTALLATION & USE GUIDE
=============================================

DOWNLOAD & SETUP
================

1. Download ChemicalScanner_Portable.zip from GitHub Releases
   (~121 MB)

2. Right-click the ZIP file and select "Extract All..."

3. Choose a location (Desktop, Documents, etc.)

4. Click "Extract"

You now have:
- ChemicalScanner.exe (the application)
- README.txt (this file)
- Launch.bat (quick launcher)


HOW TO RUN
==========

Option 1 (Recommended):
- Double-click ChemicalScanner.exe

Option 2:
- Double-click Launch.bat

First run may take 5-10 seconds to start.
Subsequent runs will be faster.


HOW TO USE
==========

Step 1: Select Your File
------------------------
- Click "Browse" button
- Select your CSV or Excel file
- File must have columns with:
  * Product IDs (e.g., "ProductId")
  * PDF URLs (e.g., "Url")

Step 2: Map Columns
-------------------
- Select "Product ID Column" from dropdown
  Example: "ProductId"

- Select "PDF URL Column" from dropdown
  Example: "Url"

- See confirmation at bottom of screen

Step 3: Choose Output Location
------------------------------
- Click "Select Output Folder"
- Pick where to save results (e.g., Desktop)

Step 4: Scan
-----------
- Click "Scan" button
- Wait for completion (takes a few seconds per PDF)
- Status shows "Scan complete" when done
- Results CSV opens automatically


INPUT FILE FORMAT
=================

Your CSV or Excel file should look like:

ProductId,Url,ProductName
CHEM-001,https://example.com/datasheet1.pdf,Cleaner
CHEM-002,https://example.com/datasheet2.pdf,Polish

Column names must match exactly.


OUTPUT RESULTS
==============

You get a CSV file with columns:

- ProductId: Your product identifier
- chemical_keywords_found: "Yes" or "No"
- chemicals_found: List of keywords detected
- keyword_occurrences: How many times each keyword appears
- pdf_url: Original URL processed
- status: success/error indicator

TROUBLESHOOTING
===============

Q: App won't start?
A: Try running Launch.bat instead
   Or check that Windows 7+ is installed

Q: "Windows Defender SmartScreen" appears?
A: Click "More info" then "Run anyway"
   This is normal for unsigned programs

Q: Error "File could not be read"?
A: Make sure file is .csv or .xlsx format
   Try opening in Excel first to verify

Q: Column dropdown is empty?
A: Check that CSV file has headers in first row
   Try re-saving file if opening Excel file

Q: No keywords found in PDF?
A: PDF might be in English (app searches German only)
   Or PDF might be an image (text not extractable)
   Try different PDF to test

Q: App is scanning very slowly?
A: Large PDFs take time to download & process
   Scanning 100+ products takes 5-30 minutes
   Check internet connection

- Make sure CSV is saved with UTF-8 encoding
- Column names must match exactly
